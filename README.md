# MemoMCP 本地记忆服务器 (Local Memory Server)

## 1. 项目简介 (Introduction)
`MemoMCP` 是一个轻量级的本地记忆服务（Memory Control Protocol）后端。本项目基于 Python 开发，旨在模拟 AI 智能助手在处理多轮对话时，如何高效地调用和存储用户的上下文记忆。通过本地化部署，该服务能够有效保护用户隐私，同时为上层 AI 应用提供快速、稳定的记忆接口支持。

## 2. 运行环境 (Environment)
- **操作系统**: Windows / macOS / Linux
- **编程语言**: Python 3.x
- **运行指令**: `python server.py`
